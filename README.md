# 👕 Style Your T-Shirt

A premium, interactive T-shirt design studio with real-time 2D editing and immersive 3D preview capabilities.

## ✨ Features

### 🎨 **2D Design Studio**
- **Drag & Drop Interface** - Upload custom images or select from curated preset collections
- **Live Canvas Editing** - Real-time manipulation with Fabric.js (resize, rotate, position)
- **Dual-View Design** - Switch between front and back perspectives
- **Color Variants** - Toggle between white and black garment options
- **Professional Controls** - Zoom, pan, fit-to-screen, and precision editing tools

### 🌐 **3D Visualization**
- **Interactive 3D Model** - Powered by Three.js with realistic T-shirt rendering
- **Smart Projection** - Accurate design placement with 100% coverage scaling
- **Context-Aware Display** - Automatically matches selected color and view (front/back)
- **OrbitControls** - 360° rotation and zoom for detailed inspection

### 📱 **Responsive Design**
- **Mobile-Optimized** - Touch-friendly controls with centered canvas layout
- **Adaptive Scaling** - Seamless experience across all screen sizes
- **Premium UI/UX** - Modern glassmorphism effects and smooth animations

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/amaanshaikh711/Style-your-TShirt.git
   cd Style-your-TShirt
   ```

2. **Launch the application**
   - Open `index.html` in a modern web browser
   - No build process or dependencies required

3. **Start designing**
   - Upload your own graphics or choose from preset designs
   - Customize placement, size, and orientation
   - Click "View in 3D" to see your creation in 3D

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3
- **2D Canvas**: [Fabric.js](http://fabricjs.com/) v5.3.1
- **3D Rendering**: [Three.js](https://threejs.org/) r132
- **3D Model Format**: GLTF/GLB
- **Design Pattern**: Modular ES6 architecture

## 📂 Project Structure

```
├── index.html          # Main application entry
├── app.js              # 2D canvas logic & event handling
├── tshirt3d.js         # 3D viewer module
├── style.css           # Responsive styling
└── assets/
    ├── *.glb           # 3D T-shirt models
    ├── *.png           # T-shirt templates & logos
    └── *.jpg/svg       # Preset design graphics
```
